1- Créer la base de donné sur mySQL 
2- Changer la fonction db_connect pour utiliser le bon localhost (généralement on change "user" et "password")
3- Lancer l'API python (faite run le fichier python)
4- Ouvrir le lien donné par le script affiché de le terminal
PS: si le fichier JSON connecter vous sur http://127.0.0.1:5000/generate-json (changer selon votre cas mais il faut /generate-json à mettre sur la fin de l'url), ce site permet de lancer la fonction qui enregistre en JSON.
